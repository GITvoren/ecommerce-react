




# Detour - Travel/EDC E-Commerce React App

**Detour** is a full-stack e-commerce web application built to demonstrate end-to-end shopping mechanics, clean architectural UI/UX, complex shopping cart state management, seamless client-side routing, user login/registration authentication, an admin management dashboard, and asynchronous API integration. Tech stack used is MERN stack. (MongoDB, ExpressJS, React, NodeJS)

## Project Goals
- Master advanced React patterns and state management.
- Implement production-grade e-commerce flows (Cart, Checkout).
- Build a dedicated Admin Dashboard for product inventory and order management.

###### Note** <br/> This repository is just its frontend. The repository link to its backend API is [here](https://github.com/GITvoren/new-ecommerce-api).

#### [Live Demo](https://detour-ecommerce.vercel.app/):point_left: (hosted on [Vercel](https://vercel.com/))

## Features
- Register user to the database
- Authenticate user login

- Admin Dashboard (For Admin Users Only)
  - Add New Product
  - Edit Product Details
  - View All Products
  - Archive Product
  - Activate Product
  - Users / Admin Users Count
  - Products / Active Products Count
  - View All Orders
  - Set User as Admin
  
- View Active Products
- Dynamic Hero Banners
- Products Category Query
- Persistent Shopping Cart
- Add to Cart
  - Added Products
  - Change Product Quantities
  - Subtotal for Each Item
  - Total Price for all items
- Checkout Order (Create Order)
